# 比赛演示证据样本

本目录文件用于“建筑材料可信交付智能核验平台”的前端演示和多模态模型识别测试。

所有企业、人员、编号和检验数据均为模拟数据，不具备质量证明、交易或工程验收效力。

## 文件对应关系

| 文件 | 使用阶段 | 关键批次号 | 说明 |
|---|---|---|---|
| `quality-certificate-sample.pdf` | 出厂建档 | `A20260718026` | 可检索文字的模拟质量证明书 |
| `factory-nameplate-sample.png` | 出厂建档 | `A20260718026` | 钢筋仓库出厂铭牌 |
| `arrival-nameplate-normal-sample.png` | 正常到场 | `A20260718026` | 与出厂批次一致 |
| `arrival-nameplate-abnormal-sample.png` | 异常到场 | `A20260718028` | 与出厂批次冲突 |

## 统一材料字段

```text
生产厂家：某钢铁有限公司
材料名称：热轧带肋钢筋
牌号：HRB400E
规格：Φ20
炉号：L202607081
生产日期：2026-07-18
采购订单编号：PO-2026-0018
```

正常案例的出厂和到场批次号均为 `A20260718026`。

异常案例只将到场铭牌批次号改为 `A20260718028`，用于验证出厂/到场身份冲突。
